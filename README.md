# 🛒 FastMart - Fresh Groceries & Household Essentials Store

**FastMart** is a modern, fast, and responsive online grocery store web application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

---

## ✨ Features

- 🥑 **Product Catalog**: Browse fresh fruits, vegetables, dairy, bakery items, and household essentials.
- 🔍 **Search & Category Filtering**: Easily search products by name or filter by category.
- 🛒 **Interactive Shopping Cart**: Add/remove items, adjust quantities, and calculate subtotals in real-time.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.
- ⚡ **Blazing Fast**: Powered by Vite and React for instant page loads and smooth animations.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS, Lucide Icons, Motion Animations
- **Build Tool**: Vite
- **Deployment**: GitHub Pages (via GitHub Actions)
