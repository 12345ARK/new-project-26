# 🛒 FastMart - Fresh Groceries & Household Essentials Store

**FastMart** is a modern, fast, and responsive online grocery store web application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

---

## ✨ Features

- 🥑 **Product Catalog**: Browse fresh fruits, vegetables, dairy, bakery items, and household essentials.
- 🔍 **Search & Category Filtering**: Easily search products by name or filter by category.
- 🛒 **Interactive Cart**: Add/remove items, adjust quantities, and calculate subtotal in real-time.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.
- ⚡ **Blazing Fast**: Powered by Vite and React for instant loading speeds and smooth UI transitions.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide React (Icons), Motion (Animations)
- **Build Tool**: Vite
- **Deployment**: GitHub Pages (via GitHub Actions)

---

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites

Make sure you have **Node.js** (v18 or higher) and **npm** installed on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 📦 Production Build

To generate the static build files for deployment:

```bash
npm run build
```

The output files will be created in the `dist` folder.

---

## 🌐 Deploying to GitHub Pages

This repository includes an automated GitHub Actions workflow (`.github/workflows/deploy.yml`).

1. Go to your repository on GitHub.
2. Click **Settings** > **Pages**.
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. Push your code to the `main` branch, and GitHub Actions will automatically build and publish your site!
